

# ⚔️ Arden'in Maceraları

Python öğrenirken yazdığım ilk projem. Arden adlı bir karakterin zindan maceraları üzerinden temel Python konularını uyguladım.

## 🎮 Programlar

| Dosya | Ne yapıyor? |
|---|---|
| soru1_xp_kesesi.py | Kesilen goblinlere göre XP, seviye ve altın/gümüş hesaplar |
| soru2_zindan_kapisi.py | Seviye ve cana göre hangi zindana girilebileceğini söyler |
| soru3_golge_lordu.py | Gölge Lordu'na karşı saldır, iksir iç, kaç gibi eylemler |
| soru4_tuccar_barnabas.py | Sınıfa göre eşya, indirim ve satın alma hesabı |
| hata_avi_duzeltilmis.py | Hatası bulunup düzeltilmiş karakter kontrol kodu |

## 🛠️ Kullandığım konular
- `input`, `print`, f-string
- Aritmetik operatörler (`//`, `%`, `**`)
- `if` / `elif` / `else`, mantıksal operatörler
- `match` / `case`

## ▶️ Çalıştırma
python soru1_xp_kesesi.py
